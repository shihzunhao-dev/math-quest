# 根號與畢氏闖關

國中數學（康軒八上第二章：平方根與畢氏定理）的闖關練習網站。純前端，學習紀錄只存在使用者自己的瀏覽器。

- 題目由參數化模板產生，每個錯誤選項對應一個常見迷思，選到時顯示針對性的說明。
- 精熟（連續答對 3 題）才解鎖下一關；精熟後安排間隔複習。
- 卡關時提供[均一教育平台](https://www.junyiacademy.org/topics/k-m8a-c02)的教學影片連結。
- 題目全部原創。

## 本機執行

```
node tools/serve.mjs      # http://127.0.0.1:8766/
node tools/stress-test.mjs 500   # 每個模板出 500 題並自檢
```

## 新增章節

在 `content/<章節id>/` 建立 `pack.js`（節點、先備關係、均一連結）、題目模板與迷思回饋，再到 `content/index.js` 登記。
